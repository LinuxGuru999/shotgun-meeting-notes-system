# Meeting Notes System

A lightweight meeting note format with decisions and owners

## Overview
This is a minimalist digital template designed for small business teams that need to stop losing track of who is doing what after meetings. It forces clarity by separating discussions from decisions and assigning specific owners to action items immediately.

## Use cases
- Weekly team standups where you need to quickly confirm task assignments
- Client check-ins where you must document agreed-upon changes and next steps
- Project kickoff meetings to establish initial responsibilities and key decisions

## How to use
1. Download the file and import it into your preferred document editor like Notion, Google Docs, or Word
2. Copy the template into your project folder and rename it with the meeting date and topic
3. Fill in the decision log and action item table during or immediately after the meeting to finalize ownership

## What is included
- Decision log
- Action item table
- Recap template
